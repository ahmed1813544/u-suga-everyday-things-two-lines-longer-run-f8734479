## What it does

`main.py` (Python 3.13, stdlib only) writes one two-line text to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Line 1 explains
a traffic jam to a 10-year-old in a single vivid sentence built on one concrete,
surprising analogy — a river that has turned to jelly. Line 2 says in one
sentence what that analogy maps and what it leaves out.

The output is fully deterministic: every run writes the same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Entry text

> A traffic jam is a river that has turned to jelly, so the cars in it can only wobble forward a tiny bit at a time.
>
> It maps how the cars are packed tight and barely move, but leaves out that real jelly is sweet and eaten with a spoon, and that the real cause is too many drivers all wanting the same road at once.
